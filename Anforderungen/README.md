# Anforderungen

Dieses Verzeichnis enthaelt die Anforderungsdokumente fuer das Projekt Ai-Tools.

## Nummernschema

Anforderungen werden fortlaufend nummeriert:

```
A001-<kurztitel>.md
A002-<kurztitel>.md
...
```

- **Praefix**: `A` gefolgt von dreistelliger Nummer (z.B. `A001`)
- **Kurztitel**: Bindestrich-getrennte Kurzbezeichnung (z.B. `shebang-zeilen`)
- **Format**: Markdown (.md)

## Beispiel

```
A001-shebang-zeilen.md
A002-logging-vereinheitlichen.md
```

## Regeln

- Anforderungsdateien werden nach Erstellung NICHT mehr veraendert
- Jede Anforderung enthaelt Akzeptanzkriterien
- Die Implementierung referenziert die Anforderungs-ID in Commit-Messages
